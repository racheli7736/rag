# 🍲 חיפוש מתכונים חכם – מערכת RAG

מערכת שמאפשרת לשאול שאלות בשפה טבעית על מאגר של מתכונים, ומחזירה תשובה שמבוססת רק על המתכונים, יחד עם המקורות שאוחזרו.

## ארכיטקטורה

```
recipes.json → Documents + metadata → SentenceSplitter (Chunks) → Gemini Embeddings → Chroma
שאלה → Retriever (top_k + סינון metadata) → Prompt → Gemini → תשובה + מקורות
```

| רכיב | בחירה | סיבה |
|---|---|---|
| ספריית RAG | LlamaIndex | דרישת התרגיל |
| LLM | `gemini-3.5-flash` | מהיר, תומך בעברית |
| Embeddings | `gemini-embedding-001` | רב-לשוני |
| Vector Store | Chroma (מקומי) | מתאים לפרויקט לימודי, נשמר בדיסק |
| קליינט | Streamlit | ממשק מהיר בפייתון |

**Chunking:** 512 טוקנים עם חפיפה של 50 (14 מתכונים → 33 מקטעים). **Retrieval:** top_k=3.

## הוראות הרצה

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # להכניס GOOGLE_API_KEY
python build_index.py       # בניית האינדקס – פעם אחת
streamlit run app.py        # הממשק
```

שאלה מהטרמינל: `python ask.py "איך מכינים חומוס?"`

## בעיות שנתקלתי בהן ואיך שיפרתי

**1. המודל היה איטי מדי**
`gemini-3.8-flash` היה עמוס (שגיאת 503), ושאלה אחת לקחה יותר מ-3 דקות.
**שיפור:** החלפתי למודל מהיר יותר, `gemini-3.5-flash`, עם `thinking_level="low"`. עכשיו תשובה לוקחת כ-2 שניות.

**2. התשובה ציינה כמה מתכונים יש במאגר**
המודל כתב למשל "במאגר ישנם שלושה מתכונים פרווה", למרות שתמיד נשלפים לכל היותר 3 בגלל `top_k=3`, ובמאגר יש 8 מתכוני פרווה. הוספתי לפרומפט "אל תענה כמה מתכונים מצאת". הוא הפסיק לציין מספר, אבל עדיין כתב "אלו המתכונים שקיימים במאגר".
**שיפור:** דייקתי את הפרומפט והסברתי לו את הסיבה: ההקשר הוא רק מדגם שנשלף לפי דמיון ולא כל המאגר. נתתי לו גם משפט פתיחה קבוע ("הנה כמה מתכונים שמתאימים לבקשה:"). אחרי זה המערכת עבדה כמצופה.

**3. נשלפו מתכונים לא מתאימים**
בשאלה על עוגה פרווה נשלפה גם עוגת גבינה (חלבי), כי היא דומה סמנטית. התברר שהמילה "פרווה" כמעט לא משפיעה על ה-Embedding: כל המקטעים קיבלו ציון דומה (0.50–0.56).
**שיפור:** הוספתי Metadata Filtering לפי כשרות וקטגוריה. Chroma מחפש רק בין המתכונים שעומדים בתנאי.

## בונוס
**Metadata Filtering** – סינון לפי קטגוריה וכשרות בסרגל הצד של האפליקציה.
